# excel/ — jalur Microsoft Excel

Folder ini untuk latihan yang **terikat ke Microsoft Excel** dan tidak (atau tidak sepenuhnya)
berlaku di Google Sheets/LibreOffice:

- PivotTable dan PivotChart (grouping, calculated field, slicer, timeline)
- Power Query: import folder, merge/append, unpivot, transformasi bertahap
- Power Pivot + DAX (measure, time intelligence)
- Fungsi modern Excel: XLOOKUP, FILTER, SORT, UNIQUE, LET, LAMBDA, TEXTSPLIT
- Macro & VBA, Office Scripts
- Tabel terstruktur + nama range sebagai basis model

Untuk latihan *rumus dasar spreadsheet* (SUM, IF, referensi absolut, format angka) gunakan folder
[`../spreadsheet/`](../spreadsheet/) — materinya sama di semua aplikasi.
